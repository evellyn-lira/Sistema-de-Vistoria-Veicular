## Descrição

O Sistema de Vistoria Veicular é uma aplicação desenvolvida em linguagem C para gerenciar o processo de vistoria de veículos. O sistema permite cadastrar clientes, veículos e vistoriadores, além de agendar e realizar vistorias, gerando relatórios com os resultados das inspeções.

O projeto foi desenvolvido utilizando estruturas (struct), vetores e funções para organizar os dados e as operações do sistema.

## Funcionalidades
- Clientes
- Cadastro de clientes
- Listagem de clientes cadastrados
## Veículos
- Cadastro de veículos
- Associação do veículo ao CPF do proprietário
- Listagem de veículos cadastrados
## Vistoriadores
- Cadastro de vistoriadores
- Listagem de vistoriadores
## Vistorias
- Agendamento de vistorias
- Registro dos itens avaliados na inspeção:
- Pneus
- Iluminação
- Freios
- Documentação
- Chassi
- Motor
- Emissão de poluentes
- Equipamentos obrigatórios
- Aprovação ou reprovação automática da vistoria

## Relatórios
- Total de veículos cadastrados
- Total de vistorias realizadas
- Quantidade de vistorias aprovadas
- Quantidade de vistorias reprovadas
- Quantidade de vistorias pendentes
